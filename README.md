# OUTPOST ZERO V3.0 — SEASON 1

솔로 탑다운 분대 습격 프로토타입입니다. GitHub 저장소에 올리고 Render Blueprint/Web Service로 배포할 수 있습니다.

## V3 핵심 변경
- 첫 화면 대폭 단순화: 출격 중심의 Season 1 로비
- 기지 건설/발전소/연구/3x3 배치 시스템은 Season 1에서 제거
- 계정 레벨에 따른 소폭의 영구 캐릭터 성장
- 한 판 약 10분
- 적 처치 시 보석 대신 카르마 자동 획득
- 본기지/카르마 교환소에서 E키로 카르마 → 크레딧 변환
- 강화는 랜덤 레벨업이 아니라 U키(모바일: 강화·상점 버튼)로 직접 구매
- 강화 3종: 공격력 / 방어력 / 속도
- 상점: 소총병 / 화염 돌격병 / 스팀팩 영구 해금
- 최대 분대 10명(플레이어 포함)
- 스팀팩 기본키 R, 설정에서 변경 가능
- 스팀팩: 최대 체력 2% 소모, 10초간 공격력/연사/이동/방어 성능 2배, 30초 쿨타임
- 스팀팩은 1회 구매 후 브라우저 저장 데이터에 영구 해금
- 적 거점은 주변에 접근하면 병력 활성화
- 적 거점 파괴 직후 대규모 증원군 등장
- 파괴된 거점도 '잔존 소굴'이 되어 약한 적을 계속 생성
- 본기지에 오래 머무르면 위협도가 더 빨리 상승하고 공격대가 강해짐
- 본기지 피격 경보/방향 표시 유지
- 소총병 사격을 3점사 기반으로 변경
- 매우 짧은 탄도선, 총구 섬광, 반동, 탄피, 피격 경직/넉백, 사망 잔상으로 타격감 강화
- 외부 에셋 없이 Canvas/CSS/WebAudio로 만든 1단계 임시 그래픽/사운드

## 조작
- 이동: WASD / 방향키
- 자동사격: 3점사
- 카르마 교환: E
- 강화·상점: U 또는 화면 버튼 / 모바일 두 번 터치
- 스팀팩: R(기본, 사용자 변경 가능)

## GitHub → Render 업데이트
기존 outpost-zero 저장소에 V3 update ZIP의 파일을 덮어쓴 뒤 Commit하면 Render의 Auto Deploy가 켜져 있을 경우 같은 주소에 자동 재배포됩니다.

## 저장
진행 데이터는 브라우저 localStorage의 `outpost-zero-meta`에 저장됩니다. 기존 V2 저장 데이터의 accountXp/runs/settings는 가능한 범위에서 이어받습니다. 기지 관련 V2 데이터는 삭제하지 않지만 Season 1에서는 사용하지 않습니다.
