# OUTPOST ZERO V4.0 — SEASON 1 · 고립

지금까지의 아이디어를 반영한 솔로 탑다운 분대 습격 프로토타입입니다. GitHub + Render 배포용입니다.

## V4 핵심 변경
- 게임 중 ESC/우측 상단 II 버튼으로 작전 메뉴: 계속하기 / 설정 / 저장하고 메인으로 / 작전 포기
- 작전 자동 저장: 10초마다, 카르마 교환, 강화, 동료 구매, 적 기지 파괴, 페이지 이탈 시 저장
- 메인 화면의 `계속하기`로 미교환 카르마·크레딧·분대·강화·남은시간·적 거점 상태 복구
- 새 출격을 선택할 때 진행 중인 작전이 있으면 확인 후 초기화
- 시즌 1에서 기지 업그레이드 시스템은 제거, 캐릭터/분대 성장에 집중
- 한 판 약 10분, 적 거점 공략 중심
- 평면 맵을 도로 / 늪지 / 숲 / 고지대 / 절벽 / 바위 / 폐허 장애물로 확장
- 장애물이 이동과 사격선을 막고, 늪·도로·고지대·숲에 간단한 지형 효과 적용
- Fog of War: 처음 방문하지 않은 곳은 어둡고, 탐험했던 곳은 희미하게 유지
- 미니맵도 탐험한 지역만 표시, 시야 밖 적은 표시하지 않음
- 적 기지 파괴 후에도 `잔존 소굴`에서 약한 적이 계속 출현
- 본기지에 오래 머무를수록 위협도 증가 및 적 공격 강화
- 카르마를 직접 줍지 않고 처치 시 자동 축적, 본기지/교환소에서 크레딧으로 전환
- 강화: 공격력 / 방어력 / 속도를 원하는 대로 직접 구매
- 상점: 소총병 / 화염 돌격병 / 스팀팩 영구 해금
- 최대 분대 10명(플레이어 포함)
- 스팀팩: 1회 영구 해금, 기본 R키(사용자 변경 가능), HP 2% 소모, 10초간 공격/연사/이동/방어 성능 2배
- 소총병 3점사, 총구 섬광/반동/탄피/피격 경직/짧은 탄도선 기반 총격감 유지
- 스토리 추가: 최초 프롤로그, 적 거점 파괴 시 기록 해금, 메인 `기록` 메뉴에서 다시 확인
- 시즌 1 완료 후 시즌 2 `전초기지 복구`가 이어지는 구조

## 조작
- 이동: WASD / 방향키
- 카르마 교환: E
- 강화·상점: U / 화면 버튼 / 모바일 두 번 터치
- 스팀팩: R 기본(설정에서 변경 가능)
- 작전 메뉴: ESC / 우측 상단 II

## 빠른 테스트
`/game.html?debug=1`
