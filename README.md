# OUTPOST ZERO V5.3.0 — Fog 복원 + 대형 괴수

V5.2.1에서 현재 시야가 직사각형/하이라이트처럼 느껴지던 문제를 되돌리고, V5.1에서 자연스럽다고 평가된 Fog 계산을 기반으로 셀만 더 촘촘하게 조정한 버전입니다.

## 핵심 변경
- Fog: V5.1의 유기적인 원형/불규칙 경계를 복원하고 셀 크기를 12px로 축소
- 미탐험 = 완전 검정 / 현재 시야 = 정상 / 탐험 완료 = 이전 지형이 보이는 어두운 기억 영역
- 장애물 뒤는 시야가 잘리고, 수풀/고지대 시야 보정 유지
- 기존 적 거점을 전부 대형 괴수로 교체
- 대형 괴수는 느리게 이동하지만 근접 강공격 피해가 매우 큼
- 상위 괴수는 충격 투사체 공격도 사용
- 괴수와 플레이어는 서로 통과하지 못함
- 괴수 사망 후 사체에서 잔존 개체가 계속 발생
- 미니맵에는 미탐험 지역에서도 대형 괴수 신호가 항상 표시
- 최종 목표는 다른 괴수를 격파한 뒤 심연군주를 제거하는 방식

## 배포
기존 GitHub 저장소에 업데이트 ZIP의 내용물을 덮어쓴 뒤 Commit하면 Render가 자동 재배포됩니다.
첫 화면과 게임 좌하단에서 `V5.3.0` 표시를 확인하세요.
