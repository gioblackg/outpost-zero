# OUTPOST ZERO V2

GitHub + Render에서 바로 배포 가능한 1인용 탑다운 2D 프로토타입입니다.

## V2 핵심 변화
- 한 판 목표 시간 10분
- 무작위 전역 웨이브 삭제: 적은 적 기지/공격대에서 출현
- 적 기지 5개: 전초기지 2, 생산기지, 요새, 지휘기지
- 적 기지 근처 접근 시 방어병력 활성화
- 적 기지 파괴 시 대규모 증원군 출현
- 적 기지를 방치하거나 본기지에 오래 머무르면 위협도 상승 → 공격대가 더 자주/강하게 출현
- 처치 보석/XP 레벨업 삭제
- 적 처치 시 카르마가 즉시 누적
- 본기지 또는 카르마 교환소에서 E 키/버튼으로 카르마 → 크레딧 교환
- 크레딧으로 원하는 능력을 직접 강화: 공격력 / 방어력 / 속도 / 스팀팩
- 레벨업 랜덤 선택 삭제
- 강화/상점 메뉴: U 키, 화면 두 번 터치, 우측 메뉴 버튼
- 상점에서 소총병 / 화염 돌격병 영입
- 플레이어 포함 최대 10명 분대, 동료는 자동 추종/자동 전투
- 동료가 죽으면 해당 출격에서 소실
- 펄스 삭제, 기존 대시는 스팀팩으로 대체
- 스팀팩 기본 단축키 R, 설정에서 변경 가능
- 본기지 공격 시 경보음, 화면 경고, BASE 방향 표시, 미니맵 점멸
- 미니맵을 우측 상단 별도 영역으로 분리
- Web Audio 기반 총격/명중/경보/교환/강화/영입/스팀팩/기지 파괴 효과음 추가

## 조작
### PC
- 이동: WASD / 방향키
- 자동 공격
- 스팀팩: R (기본값, 설정에서 변경 가능)
- 카르마 교환: E
- 강화/상점: U 또는 화면 더블클릭

### 모바일
- 가로모드
- 왼쪽 가상 조이스틱
- 오른쪽 STIM 버튼
- 강화·상점 버튼 또는 전투 화면 두 번 터치
- 교환소/본기지 근처에서 카르마 교환 버튼 표시

## 작전 목표
10분 안에 북부 지휘기지를 파괴하세요. 지휘기지를 파괴하면 12초간 마지막 역습을 버텨야 승리합니다.

## Render 배포
저장소 루트에 `render.yaml`이 포함되어 있습니다. GitHub 저장소에 전체 파일을 올린 뒤 Render의 Blueprint로 연결하면 됩니다.

## 테스트 모드
`/game.html?debug=1`

테스트 버튼:
- +60초
- 위협 +20
- +1000 C
- 소총병 추가

## 저장
기지/영구 진행과 설정은 브라우저 localStorage에 저장됩니다. 아직 계정/클라우드 저장은 없습니다.
