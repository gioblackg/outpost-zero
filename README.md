# OUTPOST ZERO V5.2.1 — Fog 핫픽스

V5.2.0에서 Fog 셀 크기만 줄고 실제 가시영역 계산은 원형 반경으로 남아 있어 큰 원형 하이라이트처럼 보이던 문제를 수정했습니다.

## 변경 사항
- 원형 반경 기반 현재 시야 계산 제거
- 4px 초미세 Fog 셀 사용
- 현재 시야를 장애물 영향을 받는 비원형 전술 시야로 변경
- 미탐험 지역: 완전 검정
- 탐험했지만 현재 시야 밖: 당시 지형은 그대로 유지되고 검은 반투명 Fog만 덮임
- 현재 시야: 정상 밝기
- 미니맵도 같은 Fog 상태를 사용
- 첫 화면 / 게임 화면 버전: V5.2.1
