# OUTPOST ZERO — 1단계 프로토타입

마린 키우기류의 즉각적인 성장 감각을 참고하되, **솔로 탑다운 생존 액션 + 기지 복구/배치 + 오프라인 생산 + 스토리 해금**으로 재구성한 웹 프로토타입입니다.

## 들어간 기능
- PC: WASD/방향키 이동, 자동 사격, `E` 펄스, `SPACE` 대시
- 모바일: 가로 화면, 가상 조이스틱 + 펄스/대시 버튼
- 12분 생존, 웨이브 증가, 6분 보스, 마지막 공세
- 경험치/레벨업, 3개 중 1개 강화 선택
- 고철 획득, 보급 상자 탐험 요소
- 중앙 기지 방어
- 출격 결과를 기지의 영구 고철/계정 경험치로 저장
- 3×3 기지 배치
- 발전소 오프라인 에너지 생산
- 에너지로 공격력/체력/고철 회수율을 최대 5단계 영구 연구
- 시설 레벨업(최대 3)
- 시설 인접 배치에 따른 특수효과
- 시설 복구와 연결된 스토리 로그
- 모든 진행은 브라우저 `localStorage`에 저장

## 빠른 테스트
브라우저 주소 뒤에 `?debug=1`을 붙이면 하단에 개발용 버튼이 생깁니다.

예: `https://YOUR-SITE.onrender.com/game.html?debug=1`

- `+60초`: 게임 시간 60초 진행
- `보스`: 보스 즉시 소환
- `레벨업`: 레벨업 선택지 즉시 표시

## 로컬 실행
Node.js 18 이상에서:

```bash
npm start
```

그 뒤 `http://localhost:3000` 접속.

## GitHub + Render 배포
1. 새 GitHub 저장소 생성 (예: `outpost-zero`)
2. 이 프로젝트의 **압축을 푼 내용 전체**를 저장소 최상위에 업로드
3. Commit
4. Render → **New + → Blueprint**
5. GitHub 저장소 연결
6. `render.yaml`을 자동으로 읽어 웹 서비스 생성
7. 배포 완료 후 Render 주소로 접속

기존 마피아 앱처럼 Render가 실제 서버를 실행하고 GitHub는 소스 코드를 보관합니다.

## 2단계 에셋 교체를 쉽게 하기 위한 방향
현재는 외부 이미지 없이 Canvas/CSS 임시 그래픽으로 만들었습니다. 이후 실제 에셋을 적용할 때 게임 로직과 메타 시스템을 유지하고 렌더링 부분만 교체할 수 있도록 분리되어 있습니다.

추천 2단계 폴더:

```text
public/assets/
  player/
  enemies/
  bosses/
  buildings/
  terrain/
  ui/
  effects/
  sound/
  music/
```

## 중요
이 버전은 **게임성 검증용 1단계**입니다. 로그인, 결제, 서버 저장, 협동/매칭은 넣지 않았습니다. 협동을 추가할 때는 서버 권한형 게임 상태/동기화 구조를 별도로 추가하는 것이 좋습니다.
